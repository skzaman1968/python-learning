# Python Learning Repository

This repository contains Python basics and intermediate topics, along with Java-style coding problems converted to Python.

## Contents

### Section 1: Python Basics and Intermediate
- Variables and data types
- Control flow
- Functions and scope
- Collections and loops
- Object-oriented programming

### Section 2: Python Coding Challenges
- Palindrome
- Reverse sentence
- Reverse words in a sentence
- First non-repeating character
- Last non-repeating character
- Reverse number
- Frequency of characters
- Factors
- Number type checks

## How to run

From the root folder:

```bash
python3 section1_basics/01_variables_and_data_types.py
python3 section2_challenges/01_palindrome.py
```

## Notes

Each file is written as a small standalone example so you can study and practice one concept at a time.
